# Charvi Salon

Website for Charvi Salon, Suncity Society. It covers hair, skin, beauty and wellness services, plus combo offers for him and her.

Built with React 18 and Vite.

## Run locally

```bash
npm install
npm run dev      # dev server
npm run build    # production build -> dist/
npm run preview  # preview the build
```

## Editing content

Prices, offers, combos, phone number and address are all in `src/data.js`.

## Photos

Service photos in `src/assets/photos/` come from [Unsplash](https://unsplash.com) under the [Unsplash License](https://unsplash.com/license), which allows free commercial use. These are stock photos. Swapping them for real photos of the salon will build more trust: keep the file names and sizes (offers 600×450, categories 800×600, combo thumbnails 240×240).
